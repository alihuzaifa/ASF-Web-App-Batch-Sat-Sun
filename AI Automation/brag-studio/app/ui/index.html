Do this once. The keys stay on this computer, in a file called .env.local. Never send that file to anyone.

Buffer posts for you on Instagram, Facebook, TikTok, YouTube, LinkedIn and X

  1. Open publish.buffer.com/settings/api and log in.
  2. Click New key, give it any name, copy it.
  3. Paste it here.

Cloudflare Pages keeps your pictures and videos online so Buffer can fetch them

  1. Open dash.cloudflare.com (a free account is enough, no card).
  2. Account ID: on the home page, click the three dots next to your account name and pick Copy account ID.
  3. Token: your picture (top right) → My Profile → API Tokens → Create Token → Custom token. Permission: Account · Cloudflare Pages · Edit. Nothing else. Create it and copy it.
